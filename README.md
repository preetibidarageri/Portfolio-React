# Preeti Bidarageri – Portfolio (React + Vite + CSS Modules)

    npm install
    npm run dev      # http://localhost:5173
    npm run build

Edit all content in `src/data/portfolio.js`. Each section is its own component in `src/components/`.
Background colour per section: `THEMES` in `Background.jsx`; each `<Section theme={n}>` picks one.
